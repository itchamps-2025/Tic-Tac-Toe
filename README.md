# Tic-Tac-Toe
A modern and responsive Tic Tac Toe game built with HTML, CSS, and JavaScript. Play against another player or challenge a smart computer opponent powered by the Minimax algorithm. Features real-time scoring, winning-cell highlights, responsive design, and a clean, minimal interface.
